# 项目简介

本项目基于 Next.js 框架构建

## 快速开始

### 安装依赖

使用下列命令安装依赖：

```bash
pnpm install
```
### 预览
```bash
# 启动预览
pnpm run dev
```
### 构建与部署

请在完成必要的配置与修改后进行以下操作：

```bash
# 构建项目
pnpm run build

# 启动生产环境服务
pnpm start
```
